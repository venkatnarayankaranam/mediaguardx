# MediaGuardX Test Dataset

30 face images for testing the deepfake detection system.

## Structure

```
test_dataset/
  fake/       15 AI-generated faces (thispersondoesnotexist.com)
  real/       15 real human faces (Unsplash, royalty-free)
```

## Expected Results

| Folder | Expected Label | Trust Score Range |
|--------|---------------|-------------------|
| `fake/` | Deepfake / Suspicious | < 45 (Deepfake) or 45-74 (Suspicious) |
| `real/` | Authentic | >= 75 |

## Usage

Upload any image from the `fake/` or `real/` folder through the MediaGuardX dashboard to test detection accuracy.

## Sources

- **Fake faces**: Generated by StyleGAN via thispersondoesnotexist.com
- **Real faces**: Royalty-free photographs from Unsplash
